# Git comandos
- git clone: Clona repositórios remotos
- git status: mostra o staus do repositório local
- git add nome-arquivo: adiciona arquivo especifico
- git add . : adiciona tudo
- git checkout -b: cria uma branch
- git commit: salva os arquivos em um repositório local
- git push: envia os arquivos paro repositório remoto
